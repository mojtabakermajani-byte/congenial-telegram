# OBD PRO فارسی — پروژه آزمایشی اندروید

## وضعیت
این یک پروژه اولیه قابل باز شدن در Android Studio است؛ APK از پیش ساخته‌شده نیست.
برای ساخت APK باید Android Studio، Android SDK و Gradle نصب باشند.

## نیازمندی‌ها
- Android Studio نسخه جدید
- JDK 17
- Android SDK Platform 35
- گوشی Android 13
- دانگل ELM327 بلوتوث کلاسیک (نه BLE)

## روش آزمایش
1. پروژه را از ZIP خارج کنید.
2. پوشه OBD_PRO_Android_Starter را در Android Studio باز کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از تنظیمات بلوتوث گوشی، ELM327 را Pair کنید (PIN معمولاً 1234 یا 0000 است؛ بسته به دانگل).
5. گوشی را با USB به رایانه وصل و USB debugging را فعال کنید.
6. در Android Studio دکمه Run را بزنید.
7. در برنامه، دانگل Pair‌شده را انتخاب و اتصال را بزنید.

## امکانات موجود
- اتصال Bluetooth Classic با پروفایل SPP
- راه‌اندازی اولیه ELM327
- خواندن RPM، سرعت، دمای آب، MAP و موقعیت دریچه گاز از PIDهای استاندارد
- خواندن DTC ذخیره‌شده (Mode 03)
- خواندن DTC در انتظار (Mode 07)
- پاک کردن DTC موتور (Mode 04) با تأیید کاربر
- نمایش پاسخ خام دانگل

## محدودیت‌ها و ایمنی
- این نسخه آزمایشی است و روی همه دانگل‌های موسوم به ELM327 تضمین‌شده نیست؛ برخی دانگل‌های تقلبی/ناسازگار پاسخ ناقص می‌دهند.
- فعلاً فقط OBD-II استاندارد موتور را هدف می‌گیرد. ABS، SRS/ایربگ، TCU، BCM، ریست سرویس و کالیبراسیون اختصاصی پیاده‌سازی نشده‌اند.
- پاک کردن خطا فقط پس از رفع علت خرابی انجام شود. این کار داده‌های تشخیصی و وضعیت آمادگی آلایندگی را نیز پاک می‌کند.
- به هیچ عنوان برای آزمایش ایربگ، مدار SRS را تحریک یا شبیه‌سازی نکنید.
- داده‌های زنده در این نسخه با فشردن دکمه به‌روزرسانی می‌شوند؛ هنوز polling خودکار و نمودار پیوسته اضافه نشده است.

## نکته اتصال
این نسخه برای ELM327 بلوتوث کلاسیک (Bluetooth Classic / SPP) است. اگر دانگل BLE باشد، مسیر اتصال متفاوت خواهد بود.


## ساخت APK بدون نصب Android Studio یا Android SDK روی کامپیوتر
این پروژه فایل Workflow دارد تا GitHub در فضای ابری APK را بسازد. برای این روش فقط مرورگر و حساب GitHub لازم است.

1. وارد GitHub شوید و یک مخزن (Repository) جدید و خالی بسازید.
2. فایل‌های داخل این پوشه را در مخزن قرار دهید؛ پوشه `.github/workflows` نیز باید همراه پروژه بارگذاری شود.
3. از سربرگ Actions، گردش‌کار `Build OBD PRO APK` را باز کنید.
4. اگر اجرا به‌صورت خودکار شروع نشده، گزینه `Run workflow` را بزنید.
5. پس از پایان موفق، وارد اجرای سبزرنگ شوید و از قسمت Artifacts فایل `OBD-PRO-debug-APK` را دانلود کنید.
6. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کنید.

این APK نسخه Debug و آزمایشی است؛ برای انتشار عمومی، امضای Release و آزمون روی چند دانگل/خودرو لازم است.
